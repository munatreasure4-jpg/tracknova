# TrackNova

Premium package tracking and shipping SaaS starter built with Next.js, Tailwind CSS, and a modern logistics dashboard.

## Features
- Premium landing page
- Tracking page with live-style map
- Login / sign up experience with TikTok-inspired dark aesthetic
- Shipping dashboard with status overview
- Mock shipment API endpoints for rapid prototype development
- Mobile-friendly responsive layout

## Stack
- Next.js 14
- React
- Tailwind CSS
- Framer Motion
- React Leaflet

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Notes
This is a polished MVP starter intended for early product validation and sales-ready presentation.
