# TrackNova

Premium package tracking and shipping SaaS starter built with Next.js, Tailwind CSS, and a modern logistics dashboard.

## Features
- Premium landing page and brand positioning
- Tracking page with live-style map
- Login and signup flows with high-end dark UI
- Shipping dashboard with status overview
- Mock shipment API endpoints for fast prototyping
- Mobile-friendly, premium responsive layout

## Stack
- Next.js 14
- React
- Tailwind CSS
- Framer Motion
- React Leaflet

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Notes
This is a polished MVP for sales-ready product presentation and rapid iteration toward a real logistics platform.
